# Jupyter Exploration

This repository was created for my GitHub and Jupyter Notebook lab. The purpose of this lab was to practice using GitHub for version control and to become familiar with working in a Jupyter Notebook environment.

During the lab, I practiced creating and editing Markdown and Python code cells, running Python code interactively, saving a notebook, and uploading project files to GitHub. This repository contains my first Jupyter notebook, `My_First_Notebook.ipynb`.

## Lab Topics
- GitHub repositories and version control
- Commits and the main branch
- Jupyter Notebook Markdown cells
- Python code cells
- Running notebook cells
- Saving and sharing `.ipynb` files

## Notebook
`My_First_Notebook.ipynb` demonstrates a basic Markdown cell and a Python `Hello, World!` example.
